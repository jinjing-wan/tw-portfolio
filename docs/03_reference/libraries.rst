库参考（Libraries，示例 软件栈示例）
=================================================

.. warning::
   本章节为 **文档体系骨架** ：统一的库参考模板、错误模型说明与评审流程由本文档体系负责；
   具体库的 API 正文（如基础线性代数库 muBLAS 类）由领域专家撰写。

库清单（占位）
----------------------------------
- 基础线性代数库（BLAS 类）：Level 1/2/3、扩展批处理；
- 深度学习加速库（DNN 类）：卷积、归一化、激活；
- 集合通信库（多卡/多机）；
- 变换库（FFT 类）、随机数库（RAND 类）。

统一库参考模板
----------------------------------
每个库参考文档应包含：

1. 编程模型
   - 上下文（Handle）创建 / 配置 / 销毁；
   - 流（Stream）绑定与异步执行；
   - 标量参数传递模式（host / device pointer）。

2. 错误状态
   - 统一返回状态码，调用后必须检查；
   - 常见错误码：无效参数 / 上下文 / 不支持 / 内部错误。

3. API 参考
   - 每个函数：签名、参数、返回值、说明、示例；
   - 数据类型与状态值集中定义。

4. 示例
   - 最小可运行样例 + ``build.sh`` + ``README``。

写作要求（文档体系）
----------------------------------------
- API 命名、参数顺序全站一致；
- 示例必须可编译运行，配套构建脚本；
- 变更走 Phase Gate（见 :doc:`/07_about/methodology`）。
