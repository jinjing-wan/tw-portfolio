# HLD Release 2.0 — 示例 AI 推理 GPU 软件栈 · 算子编译层

:::{note}
相对 [R1.0](hld_r1.md) 的 **变更摘要与新增设计**。完整基线请先读 R1.0。
分层与接口契约由本文档体系定义；**算子 kernels 与编译器内部实现由领域专家贡献**。
:::

---

## 1. 本版本变更摘要

- 新增：算子编译层（算子库 + 图编译）接入 Runtime 的接口契约；
- 新增：算子与模块的 **动态加载（热加载）**；
- 新增：告警 **分级上报 + 窗口去抖**；
- 变更：Runtime 接口契约新增字段（向后兼容，见 [API 参考](../03_reference/api.md)）；
- 优化：消费者线程异常重试与任务幂等性（回应 R1.0 的 warning）。

## 2. 新增设计：算子编译层接口

- 算子库：暴露统一算子 API，向下调用 Runtime 执行接口；
- 图编译：计算图优化（融合/调度）产出可执行任务，提交 Runtime 流；
- 契约：算子层不直接操作硬件，统一经 Runtime Context/Stream 模型。

## 3. 新增设计：动态加载

- 生效流程：请求 → 校验 → 双版本暂存 → 加载 → 一致性校验 → 回滚点；
- 回滚：加载失败自动回退上一稳定版本；
- 影响面：仅受影响子模块重载，不影响其他执行任务。

## 4. 新增设计：告警模型

- 严重级别：Critical / Major / Minor / Warning；
- 去抖窗口：重复告警按时间窗口合并，避免风暴；
- 上报通道：北向订阅 + 主动上报，带时间戳。

## 5. 可靠性增强

- 消费者重试：执行层调用失败时按退避策略重试；
- 任务幂等：同一管理操作重复下发不产生副作用；
- 背压：无界队列增加水位监控与限流（回应 R1.0 背压问题）。

## 6. 兼容性

- 接口契约新增字段向后兼容；删除/改义走 Phase Gate（见 [文档体系方法论](../07_about/methodology.rst)）；
- 升级路径：R1.0 → R2.0 配置与算子映射可平滑迁移。
