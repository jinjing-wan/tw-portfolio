## 1. 本版本变更摘要

- 新增：框架接口层（PyTorch / TensorFlow 适配）接入契约；
- 新增：推理优化（图优化 / 算子融合 / 调度策略）的文档化基线；
- 新增：**多实例（Multi-Instance）** 隔离，单卡支持多租户推理面；
- 新增：性能与可观测性目标量化（占位，见 §4）；
- 变更：北向接口契约新增批量操作（向后兼容）。

## 2. 新增设计：框架接口层

- 适配边界：框架前端经统一算子 API 调用，屏蔽底层差异；
- 接口契约：框架侧 Session/Device 映射至 Runtime Context/Stream；
- 兼容：框架版本与软件栈版本矩阵由发布说明维护（见 [发布说明](../05_release_support/release_notes.rst)）。

## 3. 新增设计：多实例隔离

- 实例模型：每实例独立配置/状态/资源上下文；
- 资源边界：实例间内存与任务队列隔离，互不影响；
- 调度：推理任务按实例路由，支持并发。
