性能优化（Performance Tuning，曦望 Sunrise 软件栈示例）
============================================================

.. warning::
   本章节为 **文档体系骨架** ：章节模板与「结论-方法-验证」写作规范由本文档体系负责；
   具体优化技术与数据由领域专家撰写。

章节骨架
----------------------------
1. 计算优化
   - Occupancy 调控（活跃线程束占比）；
   - 减少线程束分歧（Warp Divergence）；
   - 指令级并行与特化（Warp Specialization）。

2. 内存优化
   - 合并访存（Coalesced Access）；
   - 向量化访存；
   - 减少共享内存 Bank Conflict；
   - 使用常量 / 纹理内存的合适场景。

3. 执行与重叠
   - 流（Stream）划分与异步拷贝；
   - 计算与传输重叠；
   - Graph 捕获与重放。

4. 多卡 / 多机
   - 单机多卡（点对点 / 统一地址）；
   - 多机集合通信（对标 MCCL / NCCL）。

5. 优化案例（模板）
   - 每个案例： **优化前指标 → 方法 → 优化后指标** （指标占位，由专家填）；
   - 推荐案例：Reduce / GEMV / GEMM / Flash Attention（对标 MUSA 性能优化总览）。
