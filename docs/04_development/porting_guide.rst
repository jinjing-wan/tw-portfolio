移植指南（Porting Guide，曦望 Sunrise 软件栈示例）
========================================================

.. note::
   本页为 **文档体系骨架** ，迁移方案借鉴摩尔线程 **Musify** 的「CUDA → 自有架构」思路：
   结构、检查清单与评审流程由本文档体系负责，迁移映射表与技术差异由领域专家补充。

目标读者
----------------------------
已有 CUDA 代码、希望迁移到本架构（自有统一系统架构）的开发者。

迁移流程（检查清单）
----------------------------------------
1. **环境准备** ：安装 SDK 与迁移工具（见 :doc:`/01_getting_started/installation` / :doc:`/03_reference/tools`）；
2. **扫描** ：工具识别 CUDA 专属 API 与语法；
3. **映射** ：API / 语法按映射表转换（见下表骨架）；
4. **编译** ：用本架构编译器重新编译（见 :doc:`/03_reference/tools`）；
5. **验证** ：功能对齐 + 性能达标（见 :doc:`/04_development/performance_tuning`）；
6. **评审** ：PR 三方评审（见 :doc:`/07_about/methodology`）。

--------------------------------------------

语义差异与坑位（占位，由专家填）
----------------------------------------------------
- 内存模型差异；
- 同步默认行为差异；
- 库函数覆盖度差异。

验证清单
----------------------------
- [ ] 功能输出与源实现逐位/容差对齐；
- [ ] 性能不低于基线 ``<占位>``；
- [ ] 错误码路径覆盖。
