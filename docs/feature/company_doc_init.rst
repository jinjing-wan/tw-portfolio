项目概述
---------------------------------
公司文档初始化项目旨在把"知识在老人脑子里、新人看不懂"变成"统一库 + 规范 + 流水线 + 可检索"：
建立集中文档库（Single Source of Truth）、统一模板与规范、Docs-as-Code 评审发布流水线，并完成存量迁移与新人 onboarding。

本页为项目入口（Feature 节点）；完整规格（文档信息、高层级需求、按文档类型拆分的子特性与 WBTS、工时汇总）
