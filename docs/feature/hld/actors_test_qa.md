# 参与者 · 测试质量部

:::{note}
本页为「公司文档初始化项目」参与者页面之一：**测试质量部**。
按底层级需求（LL）逐条列出该角色有实际职责的部分与具体做什么；无职责 / 仅消费的 LL 不列。
条目为示例数据。
:::

## 1. 角色定位

评审与验证：评审模板可测性与步骤可复现性，作为集成测试主管参与三方评审，校验接口文档与实现一致。

## 2. 在各底层级需求（LL）中的职责

| LL | 具体做什么 |
| --- | --- |
| LL-002 | 按规范组织测试文档目录 |
| LL-004 | 评审需求验收标准可测性 |
| LL-005 | 评审 HLD 设计可测性 |
| LL-006 | 评审接口测试与文档对照 |
| LL-007 | 验证操作步骤可复现 |
| LL-008 | 验证安装环境步骤 |
| LL-009 | 提供测试结论 |
| LL-010 | 参与三方评审（集成测试主管） |
| LL-011 | 提供测试文档清单并配合迁移 |

> LL-001/012 测试质量部为「无职责」，LL-003 为「按角色使用」，均不列。

## 3. 具体操作与配置

- 模板评审中逐条核对「验收标准是否可测、手册步骤是否可复现」；
- 作为集成测试主管参与三方评审（另两方：领域技术主管、关联模块 Owner），意见留在 PR；
- 校验接口文档与实现一致性，作为「对照一致」判据。
