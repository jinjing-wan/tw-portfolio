# 参与者 · 产品部

:::{note}
本页为「公司文档初始化项目」参与者页面之一：**产品部**。
按底层级需求（LL）逐条列出该角色有实际职责的部分与具体做什么；无职责 / 仅消费的 LL 不列。
「主」表示该 LL 的主责模块。条目为示例数据。
:::

## 1. 角色定位

需求类内容主责：主导需求模板与用户场景定义，提供发布亮点，配合需求文档迁移。

## 2. 在各底层级需求（LL）中的职责

| LL | 具体做什么 |
| --- | --- |
| LL-002 | 按规范组织需求文档目录 |
| LL-004（主） | 主导需求模板内容（用户故事/功能非功能需求/验收标准） |
| LL-005 | 评审 HLD 模板与需求对齐 |
| LL-007（主） | 定义用户场景（场景工作坊 → 场景清单） |
| LL-009 | 提供发布亮点 |
| LL-011 | 提供需求文档清单并配合迁移 |

> LL-001/006/008/012 产品部为「无职责」，LL-003/010 为「按角色使用 / 消费方」，均不列。

## 3. 具体操作与配置

- 在需求模板工作坊产出「用户故事 / 功能与非功能需求 / 验收标准」三类字段；
- 按 [hl02_templates.md](hl02_templates.md) 的元数据规范补齐 frontmatter（`owner/version/status/review`）。
