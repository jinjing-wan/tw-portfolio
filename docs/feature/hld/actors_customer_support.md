# 参与者 · 客户支持

:::{note}
本页为「公司文档初始化项目」参与者页面之一：**客户支持**。
按底层级需求（LL）逐条列出该角色有实际职责的部分与具体做什么；无职责 / 仅消费的 LL 不列。
「主」表示该 LL 的主责模块。条目为示例数据。
:::

## 1. 角色定位

排障与 FAQ 内容主责：提供错误码、排障手册、FAQ 知识库，配合迁移与 onboarding 素材。

## 2. 在各底层级需求（LL）中的职责

| LL | 具体做什么 |
| --- | --- |
| LL-004 | 提供需求侧 FAQ 输入 |
| LL-006 | 提供错误码/排障文档要求 |
| LL-007（主） | 提供排障手册内容 |
| LL-008 | 提供安装排障 |
| LL-009（主） | 提供 FAQ 知识库 |
| LL-011 | 提供 FAQ/排障清单并配合迁移 |
| LL-012 | 提供排障上手内容 |

> LL-001/002/005 客户支持为「无职责」，LL-003/010 为「按角色使用 / 消费方」，均不列。

## 3. 具体操作与配置

- 在 FAQ 模板工作坊提供「错误码 / 排障步骤 / 常见问题」三类字段；
- 排障上手内容作为 onboarding 路径素材（见 [hl04_migration.md](hl04_migration.md)）。
