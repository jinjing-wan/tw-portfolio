# 参与者 · 市场售前

:::{note}
本页为「公司文档初始化项目」参与者页面之一：**市场售前**。
按底层级需求（LL）逐条列出该角色有实际职责的部分与具体做什么；无职责 / 仅消费的 LL 不列。
条目为示例数据。
:::

## 1. 角色定位

对外内容输入方：提供对外 API 清单、Demo 场景、对外 Release Notes 写法；其余多为消费方。

## 2. 在各底层级需求（LL）中的职责

| LL | 具体做什么 |
| --- | --- |
| LL-006 | 评审对外 API 清单 |
| LL-007 | 提供 Demo 手册场景 |
| LL-009 | 提供对外 Release Notes |
| LL-011 | 提供对外文档清单并配合迁移 |

> LL-001/002/004/005/008/012 市场售前为「无职责」，LL-003/010 为「按角色使用 / 消费方」，均不列。

## 3. 具体操作与配置

- 在 API 模板与发布说明模板征集中，提供「对外可见」的 API 清单与 Release Notes 写法要求；
- 提供 Demo 手册场景（面向客户演示的典型操作路径）；
- 其余需求按权限读取对外文档，无建设职责。
