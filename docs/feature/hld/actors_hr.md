# 参与者 · HR 新人培训

:::{note}
本页为「公司文档初始化项目」参与者页面之一：**HR 新人培训**。
按底层级需求（LL）逐条列出该角色有实际职责的部分与具体做什么；无职责 / 仅消费的 LL 不列。
「主」表示该 LL 的主责模块。条目为示例数据。
:::

## 1. 角色定位

onboarding 主责：定义 3-5 天新人上手路径与检查点，减少对老人口口相传的依赖。

## 2. 在各底层级需求（LL）中的职责

| LL | 具体做什么 |
| --- | --- |
| LL-007 | 提供新人上手手册需求 |
| LL-012（主） | 定义 onboarding 路径与检查点（前提：Feature-D 手册就绪） |

> LL-001~006/008/009 HR 为「无职责」，LL-010 为「消费方」，LL-011 为「受益方」，均不列。

## 3. 具体操作与配置

- 以手册 + FAQ 为素材，定义 Day1~Day5 路径与检查点：
  Day1 环境与账号 → Day2 产品概览 → Day3 核心模块文档 → Day4 动手练习 → Day5 复盘答疑；
- ramp-up 周期靠问卷定性反馈佐证（部分可测试）。
