# 参与者 · 管理层 PMO

:::{note}
本页为「公司文档初始化项目」参与者页面之一：**管理层 PMO**。
按底层级需求（LL）逐条列出该角色有实际职责的部分与具体做什么。条目为示例数据。
:::

## 1. 角色定位

决策与把关：审批选型预算、模板规范、权限策略、迁移优先级与 Phase Gate 重大发布。

## 2. 在各底层级需求（LL）中的职责

| LL | 具体做什么 |
| --- | --- |
| LL-001 | 审批平台选型与预算、确认优先级（季度规划会议） |
| LL-002 | 评审并批准目录命名规范 |
| LL-003 | 审批权限分级策略（安全合规评审） |
| LL-004 | 审批需求模板 |
| LL-005 | 审批 HLD 模板 |
| LL-006 | 审批 API 模板 |
| LL-007 | 审批手册模板 |
| LL-008 | 审批安装部署模板 |
| LL-009 | 审批发布说明/FAQ 规范 |
| LL-010 | 审批 Phase Gate 重大发布（放行或回滚） |
| LL-011 | 审批迁移优先级与资源 |
| LL-012 | 审批 onboarding 路径 |

## 3. 具体操作与配置

- HL-01 选型与预算为前置门禁：未批准前不启动搭建；
- 模板/规范评审通过后签发批准（HL-02）；
- 重大发布基于发布快照决定「放行」或「回滚」（HL-03）。
