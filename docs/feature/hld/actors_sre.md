# 参与者 · 运维 SRE

:::{note}
本页为「公司文档初始化项目」参与者页面之一：**运维 SRE**。
按底层级需求（LL）逐条列出该角色有实际职责的部分与具体做什么；无职责 / 仅消费的 LL 不列。
「主」表示该 LL 的主责模块。条目为示例数据。
:::

## 1. 角色定位

基础设施与部署主责：静态站托管、域名、CI 环境、SSO 鉴权，部署/回滚文档与运维文档。

## 2. 在各底层级需求（LL）中的职责

| LL | 具体做什么 |
| --- | --- |
| LL-001 | 提供静态站托管、访问域名与 CI 运行环境 |
| LL-002 | 按规范组织运维文档目录 |
| LL-003 | 配置平台鉴权与 SSO / 分组 |
| LL-005 | 评审 HLD 部署架构部分 |
| LL-006 | 评审运维接口文档 |
| LL-007 | 提供运维/排障手册 |
| LL-008（主） | 定义部署/回滚文档 |
| LL-009 | 提供升级注意事项 |
| LL-010 | 托管 CI 运行环境与静态站 |
| LL-011 | 提供运维文档清单并配合迁移 |
| LL-012 | 提供运维上手内容 |

> LL-004 运维 SRE 为「无职责」，不列。

## 3. 具体操作与配置

```nginx
# 静态站托管（示例）
server {
    listen 80;
    server_name docs.internal.example;
    root /srv/docs/_build/html;
    index index.html;
}
```

- 三级权限（公开/内部/机密）在托管层落地：公开走匿名，内部/机密走 SSO + 分组；
- 提供内网 PyPI / npm 镜像，保证构建机离线可构建。
